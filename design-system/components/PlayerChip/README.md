A player's identity in multiplayer games: a colour plus a shape for each of eight seats (`coral` circle, `aqua` square, `lime` triangle, `orchid` diamond, `sky` star, `sand` hexagon, `peach` plus, `periwinkle` pentagon), so players can be told apart without seeing colour.

**Consumer provides** the `player` seat number (0–7), an optional nickname, and an optional `detail` such as a score. Without a nickname the colour name is shown ("Coral wins 3–1").
