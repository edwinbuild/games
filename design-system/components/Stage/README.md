The outlined `surface` a game is played on: one per page, directly under the instructions.

**Consumer provides** the game itself as children. `color` fills it with a game colour (text switches to `on-fill`), for states like the Reaction Chain panel turning green; `flush` tightens the padding for grids.

- Do keep everything the player needs to act on inside the stage.
- Don't nest a stage inside a stage or a ticket.
