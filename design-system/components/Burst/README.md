A one-shot ring of dots for a payoff moment: a new personal best on the ticket, a perfect cut, the last piece clicking in. Half the dots take the game colour, half `on-fill`, so it reads on any background. It plays once when it mounts; give it a new `key` to play it again.

**Consumer provides** a positioned parent, and optionally `x` and `y` (CSS lengths inside that parent, default the centre), `color` (a game colour token) and `count` (12–20 dots).

- Use it only for real achievements, at most once per moment. Never on every tap.
- Hidden entirely with reduced motion; pair it with a sound (`feel.chime`) so the moment still lands.
