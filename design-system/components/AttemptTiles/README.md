A row of small tiles showing each attempt: hit (✓, `mint`), near (~, `ticket`), miss (✕, `chili`), or empty (dashed).

It mirrors the 🟩🟨🟥 squares in the share text, so the player sees on screen what friends will see in the chat. Each tile carries a glyph so colour is never the only signal.

**Consumer provides** the list of attempts. The game decides what counts as hit, near and miss.
